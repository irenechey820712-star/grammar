관계부사  /  결과를 나타내는 so ~ that
Student ID
Name
Point 1 관계부사
  • 관계부사절은 관계대명사절처럼 절 앞의 명사(선행사)를 꾸며주는 형용사 역할을 한다. 그러나 관계부사 다음에는 완전한 절이 오고, 관계대명사 다음에는 불완전한 절이 온다.
  • 선행사의 종류에 따라 when(시간), why(이유), where(장소), how(방법)의 관계부사가 쓰인다. 단, the way는 how와 함께 쓸 수 없으므로 둘 중 하나만 쓴다.
  • 관계부사는 「전치사 + 관계대명사」로 바꾸어 쓸 수 있다.
예시
The time when(= at which) he came home was very late.
그가 집에 돌아온 시간은 매우 늦었다.
Our science teacher explained the reason why(= for which) there were more tropical nights this year.
과학 선생님은 왜 올해 더 많은 열대야가 있었는지 그 이유에 대해 설명해 주셨다.
The captain already knows the place where(= at which) the treasure is buried.
선장은 보물이 묻힌 장소를 이미 알고 있다.
▶ 선행사 – 관계부사 – 전치사+관계대명사 대응표
선행사 (Antecedent) 관계부사 = 전치사 + 관계대명사 선행사 생략 가능?
시간 명사
the time, the day, the year…		 when at / on / in which ✔ 가능
이유 명사
the reason		 why for which ✔ 가능
장소 명사
the place, the city, the house…		 where at / in / on which ✔ 가능
방법
the way (선행사 자체가 생략)		 how in which ⚠ the way 또는 how 중 하나만
CHECK관계부사 vs. 관계대명사 구별법
관계부사 뒤에는 완전한 절(S+V 모두 존재)이 오고, 관계대명사 뒤에는 불완전한 절(S 또는 O 빠짐)이 온다.
구분 예문 구조
관계부사 This is the city where I was born. where 뒤 → I was born (완전한 절 ✔)
관계대명사 This is the city that / which I love. that 뒤 → I love ___ (목적어 빠짐 ✔)
※ 뒤에 오는 절이 완전하면 → 관계부사 / 불완전하면 → 관계대명사
TIPthe way와 how는 함께 쓸 수 없다!
the way how ✗  →  the way ✔  또는  how ✔  또는  the way in which ✔
예) I like the way she explains grammar.  /  I like how she explains grammar.  → 둘 다 OK
    I like the way how she explains.  → ✗ (함께 사용 불가)

Point 2 결과를 나타내는 so ∼ that
  • 사람 또는 사물의 행위나 상태 때문에 특정한 결과가 야기된 상황에서 쓰인다. '너무나 ~해서 (그 결과) …하다'라는 의미를 가진다.
  • 「so + 형용사/부사 + that절」 형태로 쓰이며 that 뒤에 결과에 해당하는 내용이 온다.
  • 목적을 나타내는 so that(~하기 위해서)과 구별하여 사용해야 한다.
예시
The book was so interesting that I finished it in one day.
그 책은 너무 재미있어서 나는 하루 만에 그것을 다 읽었다.
They spoke so loudly that everyone in the room could hear their conversation.
그들이 너무 크게 말해서 그 방에 있던 모든 사람이 그들의 대화를 들을 수 있었다.
▶ so ~ that (결과) vs. so that (목적) 비교
구분 형태 의미 예문
결과 so + 형/부 + that 너무 ~해서 …하다 She was so tired that she fell asleep.
목적 so that + S + can/will/may ~하기 위해서 He studied hard so that he could pass.
※ 구별 포인트: so 바로 뒤에 형용사 또는 부사가 오면 결과 구문  /  so 바로 뒤에 that S + V가 이어지면 목적 구문
CHECKsuch ~ that 구문과 비교하기
so ~ that과 같은 의미의 such ~ that 구문도 자주 출제된다.
구문 형태 예문
so ~ that so + 형용사/부사 + that It was so cold that we stayed inside.
such ~ that such + (a/an) + 형용사 + 명사 + that It was such cold weather that we stayed inside.
※ so 뒤에는 형용사/부사, such 뒤에는 명사(구)가 온다는 점이 핵심 차이!
TIPso ~ that 결과 구문의 변환 패턴
so ~ that (결과) too ~ to (부정 결과) ~ enough to (긍정 결과)
He was so tired that he couldn't work. He was too tired to work. —
She was so strong that she could lift it. — She was strong enough to lift it.
※ 부정 결과(couldn't / was unable to)는 too ~ to로 전환, 긍정 결과는 ~ enough to로 전환 가능
